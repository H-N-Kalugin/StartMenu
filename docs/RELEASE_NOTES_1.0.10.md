# StartMenu 1.0.10

A fix for games. Update from inside the app: click the pulsing dot next to the version number in the bottom-right corner of the menu → **Update**.

## 🎮 Games in a full-screen window

- **No more Start menu popping up mid-game.** In games running in a borderless full-screen window (for example World of Warcraft), clicking the corner where the Start button would be — say, on an action bar — opened the menu, because the taskbar was still there, just hidden behind the game. Now a click opens the menu only when the taskbar is really under the cursor; otherwise it goes to the game.
- **The taskbar goes back under the game** after you close the menu that you opened over it with the Win key.

The Win key keeps working as before: over a game it opens the menu together with the taskbar.

<summary><b>🇷🇺 По-русски</b></summary>

Исправление для игр. Обновиться можно прямо из программы: нажмите пульсирующий кружок рядом с номером версии в правом нижнем углу меню → **Обновить**.

**Игры в окне на весь экран**
- **Меню больше не выскакивает посреди игры.** В играх в окне без рамки на весь экран (например, World of Warcraft) клик в углу, где стоит кнопка «Пуск» — скажем, по панели заклинаний, — открывал меню: панель задач оставалась на месте, просто под игрой. Теперь клик открывает меню, только если под курсором действительно панель задач; иначе он уходит в игру.
- **Панель задач возвращается под игру** после закрытия меню, открытого поверх неё клавишей Win.

Клавиша Win работает как раньше: над игрой открывает меню вместе с панелью задач.
