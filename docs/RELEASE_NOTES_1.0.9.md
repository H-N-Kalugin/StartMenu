# StartMenu 1.0.9

Smarter updates. Update from inside the app: click the pulsing dot next to the version number in the bottom-right corner of the menu → **Update**.

## 🔄 Updates

- **Always the newest version.** If several versions came out since the last check, StartMenu now checks again right before installing and goes straight to the newest one — no more stepping through updates one by one. Works everywhere: the version menu, the tray, the sidebar, Settings and automatic updates.
- **Fresh check when you click the version number.** The dot and the label learn about a new version right away instead of waiting for the next scheduled check.
- **Clearer version menu.** The top line is now a plain caption — “Installed: StartMenu 1.0.9” — instead of something that looked like a button.

<summary><b>🇷🇺 По-русски</b></summary>

Более умные обновления. Обновиться можно прямо из программы: нажмите пульсирующий кружок рядом с номером версии в правом нижнем углу меню → **Обновить**.

**Обновления**
- **Всегда самая новая версия.** Если с прошлой проверки вышло несколько версий, StartMenu проверяет ещё раз прямо перед установкой и сразу ставит самую новую — без обновления по одной версии за раз. Работает везде: в меню версии, в трее, на боковой панели, в настройках и при автообновлении.
- **Свежая проверка по клику на номер версии.** Кружок и надпись узнают о новой версии сразу, а не при следующей плановой проверке.
- **Понятнее меню версии.** Верхняя строка — теперь просто подпись «Установлена версия StartMenu 1.0.9», а не что-то похожее на кнопку.
