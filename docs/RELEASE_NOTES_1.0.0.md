# StartMenu 1.0.0 — first public release 🎉

**Your Windows 10 tiles, back in Windows 11 — free, beautiful and safe.** Groups, folders, 4 tile sizes and instant search in a standalone app that doesn’t patch Windows, needs no admin rights and uninstalls in one click. No ads, no keys, no subscriptions.

![StartMenu](https://raw.githubusercontent.com/NKF-XXX/StartMenu/main/docs/images/hero.png)

## ⬇️ Download

**[StartMenu-1.0.0.exe](https://github.com/NKF-XXX/StartMenu/releases/download/v1.0.0/StartMenu-1.0.0.exe)** · ~11 MB · Windows 11 x64

> The installer is not code-signed yet. If SmartScreen shows *“Windows protected your PC”*, click **More info → Run anyway**.
> No administrator rights needed — it installs for your user only and can be removed from *Settings → Apps → Installed apps*.

## ✨ Highlights

- 🧱 **Tiles in groups** — 4 sizes, folders, tabs inside a group, list-view groups, custom pictures, fill with icon color.
- 📑 **Layers** — extra pages of tiles, `Ctrl+1…9` to switch.
- 🎨 **4 styles** — Classic, Studio, Bento and Fluent, each fully customizable (glass, blur, colors, corners, animation).
- 🔎 **Search** — apps, Windows Settings, files, web, built-in calculator; understands transliteration and the wrong keyboard layout.
- 🎵 **Music player** — compact in the search bar or a large panel above the menu with cover, seeking, waveform and beat glow.
- 🌗 **Light and dark theme** for every style — or follow Windows automatically.
- 💾 **Your layout is safe** — automatic daily backups (last 7), restore in one click, save/load the menu to a file.
- 🔔 **Update check** — once a day, quietly; a dot on Settings when a new version is out, update in one click.
- ⏸️ **Pause** from the tray — `Win` opens the Windows menu again until you resume.
- 🔊 **Volume & output device** in the menu; 📎 **clipboard history** and 📊 **system monitor** — optional, off by default.
- 🌐 **Website links** with real site icons; 📌 **“Pin to StartMenu”** in Explorer.
- 🎮 **Works over fullscreen games** — the taskbar comes up together with the menu.
- 🧙 **First-run wizard** with live style previews and import of what’s pinned in the Windows Start menu.
- 🌍 **12 languages**: English, Русский, Українська, Deutsch, Français, Español, Italiano, Português, Polski, Türkçe, 中文, 日本語.

## 💡 Good to know

- The native Windows Start menu is always one shortcut away: **`Ctrl+Esc`**.
- If Start11 is running, StartMenu warns once — close one of them so they don’t compete for the `Win` key.
- To move your layout to another PC: *Settings → Backups and updates → Save menu to file*, then *Load from file* on the other PC.
- StartMenu is vibe-coded: the code was written by the AI assistant [Claude Code](https://claude.com/claude-code) and tested by hand. Please report anything odd.
