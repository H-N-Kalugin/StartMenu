# StartMenu 1.0.5

Switches instead of checkboxes, mouse control over free shortcuts, a version menu and a new choice in the first-run wizard. Update from inside the app: click the pulsing dot next to the version number in the bottom-right corner of the menu → **Update**.

## 🎛️ Clearer choices

- **Switches instead of checkboxes.** Every on/off option in Settings and in the first-run wizard is now a pill: the chosen side is a highlighted button, the other is dimmed text. One click anywhere on the row flips it.
- **Labels choice in the wizard.** Pick tiles *With labels* or *No labels* on the very first screen — the previews update instantly. A note reminds you that everything can be changed later in **Menu settings → Tiles and window** or by right-clicking an empty spot.

## 🧩 Free shortcuts

- **Width and alignment by mouse.** Drag on the empty part of a free-shortcut block to set its width; tiles line up left / center / right inside it. The default is *fit to shortcuts*. Left and right indents are set in tile steps.

## ⚙️ Updates

- **The version number is always clickable.** A small menu: update (when there is one), hide the notice, check now, plus toggles — *Notify about new versions*, *Install automatically* (off by default; never during full-screen games), *Show “What's new”*.
- **“What's new” card** now has a *Don't show again* checkbox.

Переключатели вместо галочек, управление свободными ярлыками мышью, меню версии и новый выбор в мастере первого запуска. Обновиться можно прямо из программы: нажмите пульсирующий кружок рядом с номером версии в правом нижнем углу меню → **Обновить**.

**Понятнее выбор**
- **Переключатели вместо галочек.** Все варианты «вкл/выкл» в настройках и в мастере — теперь «таблетка»: выбранная сторона подсвечена кнопкой, вторая — тусклый текст. Клик в любом месте строки переключает.
- **Подписи — в мастере.** На первом экране выбираете плитки **с подписями** или **без подписей**, превью меняется сразу. Подсказка напоминает, что всё можно изменить позже: **Настройки меню → Плитки и окно** или ПКМ по пустому месту.

**Свободные ярлыки**
- **Ширина и выравнивание мышью.** Тяните по пустому месту блока — меняется ширина; плитки встают слева / по центру / справа. По умолчанию — «по размеру ярлыков». Отступы слева и справа — в шагах плитки.

**Обновления**
- **Номер версии всегда кликабелен.** Небольшое меню: обновить (если есть), скрыть уведомление, проверить сейчас и переключатели — «Уведомлять о новых версиях», «Устанавливать автоматически» (по умолчанию выключено, не во время полноэкранных игр), «Показывать «Что нового»».
- **Карточка «Что нового»** теперь с галочкой «Больше не показывать».
