# StartMenu — документация для разработчика

> Техническое описание проекта (на русском): сборка, устройство, служебные ключи, где что лежит.
> Обзор для пользователей — в [README](../README.md) · [README на русском](../README.ru.md).


## Сборка (Windows)
1. Qt 6.8.3 (msvc2022_64) стоит в `C:\Qt` (поставлен через aqtinstall из `.tools\venv`).
2. Закрой `StartMenu.exe` в трее (иначе exe занят) и запусти `build.cmd`:
   CMake + Ninja (из VS 2022), Release, windeployqt без лишних плагинов.
3. Запусти `build\StartMenu.exe`. Иконка появится в трее.

## Установщик для передачи
`pwsh -File installer\make-installer.ps1` → `dist\StartMenu-1.0.0.exe` (~11 МБ, собирается встроенным в Windows IExpress).
Ставит для текущего пользователя без прав администратора в `%LOCALAPPDATA%\Programs\…`:
ярлыки «StartMenu» и «Настройки StartMenu» в меню «Пуск», автозапуск, запись в «Установленных приложениях»
(удаление — оттуда или `uninstall.ps1` в папке программы). Библиотеки Visual C++ лежат рядом — ставить vc_redist не нужно.
Файл не подписан, поэтому SmartScreen при первом запуске может показать «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».
**Подпись кода** (убирает это предупреждение): нужен сертификат разработчика от центра сертификации (или Microsoft Trusted Signing).
Когда он есть — задайте перед сборкой `STARTMENU_SIGN_PFX` + `STARTMENU_SIGN_PASSWORD` (файл .pfx) или `STARTMENU_SIGN_THUMBPRINT`
(сертификат в хранилище Windows), и `make-installer.ps1` сам подпишет StartMenu.exe и установщик (signtool из Windows SDK, метка времени DigiCert).

## Как устроено
Один exe, три режима — каждый отдельным процессом, чтобы в простое в памяти был только трей (~4 МБ):
- `StartMenu.exe` — трей: хук клавиши Win и клика по кнопке «Пуск», сторожок хука.
- `StartMenu.exe --menu` — окно меню; запускается по Win, при закрытии процесс завершается.
- `StartMenu.exe --settings` — окно настроек; изменения сразу применяются к открытому меню.

Служебные ключи: `--nohook` (без перехвата), `--show` (сразу открыть меню), `--menu --preview`
(меню не закрывается само), `--query "текст"` (открыть с поиском), `--export-icons <папка>`
(иконки плиток в PNG), `--render файл.png [стиль 0..3]` (меню в картинку без показа), переменная `STARTMENU_PERF=<файл>` — время до первой отрисовки и память.

Снимки для страницы проекта — без личных данных:
`--render файл.png [стиль 0..3] --demo [--lang en] [--clipboard-view] [--large-player | --compact-player] [--demo-glow]`.
С `--demo` всё выдуманное и только в памяти (settings.json, items.json и история буфера не читаются и не пишутся):
нейтральные плитки с цветными значками-заглушками, 2 слоя, группа-список «Ссылки»; стиль — из пресета
«Стандартный для стиля»; 6 записей буфера; трек «Northern Lights» 1:24 / 3:30 (плеер — только с `--large-player`
или `--compact-player`); монитор: ЦП 7 %, ОЗУ 9,8 / 32 ГБ, ГП 12 %, диск 512 ГБ. Код — `src/Demo.cpp`.
Мастер первого запуска: `--welcome --welcome-shots <папка> [--lang en]`, окно настроек: `--settings-shots <папка> [--lang en]`.
Ещё ключи `--render` (всё только в памяти): `--transparent` — PNG с прозрачностью (стекло и просвет между плеером и меню;
без него подложка заливается серым), `--items <файл>` — раскладка из копии items.json (например, с нейтральными названиями),
`--default-style` — цвета стиля из его пресета, а не сохранённые, `--labels` / `--no-labels` — подписи плиток,
`--size 1400x560` — размер окна.

Сборка и надёжность (проход 22.11.2026): перехват Win/мыши живёт в своём потоке трея (`KeyHook.cpp`), чтобы занятость
основного потока не тормозила ввод; файлы настроек, плиток и истории буфера читаются и пишутся под межпроцессным
замком `FileLock` (`Config.h`); в сборку кладутся плагины форматов JPEG/GIF/ICO (`build.cmd`).

## Как пользоваться
- **Win** или клик по кнопке «Пуск» — открыть/закрыть. Комбинации Win+… работают как обычно. Родной «Пуск» — Ctrl+Esc.
- **Группы**: заголовок — двойной клик переименовать, перетащить — переместить; правый край — ширина;
  ПКМ — стиль, цвет фона, вкладки, удалить. Вкладки переключаются кликом.
- **Плитки**: 4 размера (ПКМ → «Размер»), перетаскивание между группами, в пустое место — новая группа,
  на центр другой плитки — папка. Файлы из Проводника можно бросать прямо в группу. Стрелки + Enter — с клавиатуры.
- **Рабочие пространства**: значок «слои» на боковой панели или Ctrl+1…9.
- **Поиск**: просто печатай. Калькулятор (`(12+3)*2,5`), страницы «Параметров», «Найти файлы», «Искать в интернете».
  Строку из результатов или «Всех приложений» можно перетащить в группу.
- **Плеер** — что играет в Windows (Spotify, браузер…): компактный в строке поиска или большой панелью над меню
  (обложка миниатюрой или фоном, ползунок-волна с перемоткой). Клик по треку — раскрыть, «⌄» — свернуть, ✕ — пауза
  и скрыть до следующего воспроизведения, ПКМ — вид. Код: `src/MediaSession.*` (C++/WinRT), `src/MediaPlayer.*`, `src/PlayerWindow.*`.
- **Первый запуск**: если настроек ещё нет, трей открывает мастер (`--welcome`, `src/Welcome.*`): стиль по живым превью,
  приложения для группы «Избранное» или пустое меню с подсказкой.
- **Слои** — страницы плиток: «1 2 +» рядом с поиском (клик, колёсико, Ctrl+1…9; ПКМ — переименовать/удалить).
- **Группа-список**: ПКМ по группе → «Вид: список» — строки (значок + название) вместо квадратных плиток.
- **Папки и ссылки на сайты**: ПКМ по группе → «Добавить папку…» / «Добавить ссылку на сайт…», или перетащить ссылку
  из адресной строки браузера. Иконка сайта скачивается сама; браузер для ссылок — в настройках («Поведение»).
- **Буфер обмена** (кнопка слева, точка — есть новое): история пишется треем, клик — вставить в окно, где был курсор.
  Пароли из менеджеров паролей не сохраняются. **Звук** — кнопка слева: громкость, «без звука», устройство вывода.
- **Языки**: русский, английский, украинский, немецкий, французский, испанский, итальянский, португальский, польский,
  турецкий, китайский, японский. По умолчанию — как в Windows; выбор — в мастере и в настройках. Строки в коде — `TXT("…")`,
  переводы — `i18n/<код>.json` (индекс строки из `i18n/keys.json` → перевод), встраиваются в exe.
- **Start11**: если он запущен, наш перехват Win держится первым, а трей один раз предупреждает — Start11 лучше закрыть.
- **Строка внизу**: при наведении на плитку — название, группа и где лежит файл (для ярлыка — куда он ведёт).
- **Окно**: тяни за верхний/боковые края — размер; плитки подстраиваются (адаптивная раскладка).
- **Настройки**: трей → «Настройки…», ПКМ по пустому месту меню или по значку «Параметры».
  Стиль оформления: Классический / Studio / Bento / Fluent (код — `src/Skin*.cpp`).
- **Группы в ряд**: перетащи группу за заголовок на правую половину другой группы — встанет справа от неё.
- **Скорость**: обычно меню открывается за ~0,1 с; с «Держать меню наготове» (Поведение) — за ~0,02 с
  ценой ~9 МБ памяти в простое. Список приложений для поиска кэшируется на диске.

## Где что лежит
- `src/Theme.h` — размеры и цвета по умолчанию; часть перезаписывается из `settings.json`.
- `src/Workspace.*` — группы и плитки, `src/AppList.*` — список/поиск, `src/Sidebar.*` — левая панель,
  `src/StartWindow.*` — окно меню, `src/KeyHook.*` — перехват ввода, `src/Shell.*` — всё про Windows Shell.
- `%APPDATA%\…\StartMenu\items.json` (трей → «Открыть папку с настройками») — пространства, группы, плитки; `settings.json` — внешний вид.
- `%LOCALAPPDATA%\…\StartMenu\cache\icons` — кэш иконок.
- `tools/import-start11.ps1` — перенос групп из Start11 (только читает его настройки).
- `design/` — бриф и концепции редизайна.
