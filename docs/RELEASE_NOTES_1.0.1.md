# StartMenu 1.0.1

Fixes for tile icons. Update from inside the app: when a new version is out, a pulsing dot appears next to the version number in the bottom-right corner of the menu — click it and choose **Update**.

## 🛠 Fixed

- **Colored fringe around some icons.** Apps from the Microsoft Store (Claude, ArtCraft Launcher and others) showed a dotted green/yellow outline around the icon. Fixed, and the broken cached icons are rebuilt automatically.
- **Icons that vanished on a colored tile.** With *Fill tiles with the icon color*, an icon without its own background (just a shape, like the ArtCraft “A”) had the same color as its tile and almost disappeared. Such tiles now get a contrasting background.
