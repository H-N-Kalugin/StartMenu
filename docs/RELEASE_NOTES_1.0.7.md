# StartMenu 1.0.7

A small fix for the light theme. Update from inside the app: click the pulsing dot next to the version number in the bottom-right corner of the menu → **Update**.

## ☀️ Light theme

- **Readable group tabs in Bento.** In the light theme, group tabs (for example *Social | Tools*) were drawn as a dark pill with dark text and were hard to read. Now the active tab is a white pill on a light track.

## 🌐 Website

- The project site now has a **light / dark switch** in the top-right corner, with screenshots of the menu in the matching theme.
