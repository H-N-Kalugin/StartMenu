# StartMenu 1.0.2

Free-standing shortcuts, a handier search menu, faster icons and a more reliable update notice. Update from inside the app: click the pulsing dot next to the version number in the bottom-right corner of the menu → **Update**.

## ✨ New

- 🧩 **Shortcuts without a group.** Drag a shortcut out of a group onto an empty spot and it stays a free tile — no new group is created. Free tiles line up by themselves in tidy rows and adapt to the window size; drop more of them nearby and they join the same block. Right-click the block to turn it into a normal group, add a folder or a link, or change its width.
- 📂 **Open file location** for apps from the Windows app list and for Microsoft Store apps (Discord, Telegram, Chrome, Claude…) — it was missing in the search results menu. For a shortcut it opens the program the shortcut points to.

## ⚡ Improved

- **Icons appear faster.** After you pin apps or finish the setup wizard, icons are prepared in the background, so tiles show up with their icons right away.
- **Update notice is more reliable.** The menu now checks for new versions every couple of hours and each time you open it (it used to wait up to a day), so the dot shows up soon after a release.

<summary><b>🇷🇺 По-русски</b></summary>

Свободные ярлыки без группы, удобное меню поиска, быстрые иконки и более надёжное уведомление об обновлении. Обновиться можно прямо из программы: нажмите пульсирующий кружок рядом с номером версии в правом нижнем углу меню → **Обновить**.

**Новое**
- **Ярлыки без группы.** Вытащите ярлык из группы на пустое место — он останется свободным, новая группа не создаётся. Свободные плитки сами выстраиваются ровными рядами и подстраиваются под размер окна; следующие, брошенные рядом, ложатся в тот же блок. ПКМ по блоку: превратить в группу, добавить папку или ссылку, изменить ширину.
- **«Открыть расположение файла»** для программ из списка Windows и приложений Microsoft Store (Discord, Telegram, Chrome, Claude…): в меню результатов поиска этого пункта не было. У ярлыка открывается программа, на которую он ведёт.

**Улучшено**
- **Иконки появляются быстрее.** После закрепления программ или мастера настройки иконки готовятся в фоне, и плитки сразу показываются с иконками.
- **Уведомление об обновлении надёжнее.** Меню проверяет новые версии каждые пару часов и при каждом открытии (раньше ждало до суток), поэтому кружок появляется вскоре после выхода релиза.
